# Mystro Security

Executive protection, VIP bodyguard services, armed security, and rapid response patrol website built with Next.js and Tailwind CSS.

## Features
- Modern, responsive Next.js 15 web application
- Tailwind CSS styling
- Static HTML export optimized for GitHub Pages and web hosting
- Automated deployment via GitHub Actions

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
